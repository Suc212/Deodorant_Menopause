# Korret Deals Landing Project

A React/Vite project based on the imported Velvety natural deodorant landing page template.

## Commands

```bash
npm install
npm run dev
npm run build
```

## Structure

- `src/main.jsx` contains the page components.
- `src/data.js` contains editable product copy, pricing, benefits, reviews and related products.
- `src/styles.css` contains the design system and responsive layout.

Replace the placeholder SVG product drawings with real product photos when assets are ready.
